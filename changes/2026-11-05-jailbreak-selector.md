- **Give a bot a jailbreak prompt, straight from the app.** In Bots → a bot → "🔓 Jailbreak templates" you can download
  the template collection and apply one to that bot: every new chat in it starts with that prompt, and chats you already
  have keep the one they built. "Restore" puts the bot's previous personality back. The templates sync from the community
  collection at github.com/togg53192-cmd/jailbreaks, so the list stays current. Verified with the plugin and web checks.
