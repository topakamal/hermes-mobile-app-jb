- **Multiple API keys for a custom endpoint.** Open a custom (OpenAI-compatible) endpoint's sheet and use Add another key to give it several keys — when one runs out of tokens or is rate-limited, Hermux automatically switches to the next key. Just like Google AI Studio and OpenRouter.
- **Batch add API keys.** For any provider that supports several keys (custom endpoints included), use Batch add to paste many keys at once or pick a `.txt` file — one key per line — and Hermux adds them all to the rotation pool.
